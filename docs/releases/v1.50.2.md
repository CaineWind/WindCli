# WindAgent 1.50.2 · Windows

正式发行页：https://github.com/CaineWind/WindCli/releases/tag/v1.50.2

Windows x64 安装包：https://github.com/CaineWind/WindCli/releases/download/v1.50.2/windagent-desktop-1.50.2-win-x64.exe

## 本次更新

- **桌面端不再弹网页版提示**：桌面客户端不再出现「新版本已准备就绪 · Reload」和「下载完整离线资源」。桌面端的界面随安装包提供、由客户端自己更新，因此不再使用网页版的离线缓存，并会在启动时清掉旧版本留下的缓存。以前升级后第一次打开，可能一直显示旧版界面，直到点 Reload。
- **WindBrowser 标签页图标**：内置 WindBrowser MCP 0.1.3（Chrome 扩展 2.4.5）。扩展接管的每个标签页，图标会变成 Agent 光标，一眼能看出 Agent 正在操作哪些标签；结束调试或空闲释放后恢复页面原来的图标，在 Chrome 顶部取消调试时 90 秒内恢复。同时包含 0.1.2 之后积累的扩展连接修复（旧连接残留、连接状态与服务核对、服务/扩展/Chrome 重启后自动恢复）。请在「浏览器」设置里按提示更新扩展到 2.4.5。

完整列表见发行页说明。

## 安装与更新

这是 Windows x64 的正式稳定版本，包含配套本机 Agent 服务及其运行依赖，不需要额外安装 Node.js 或独立服务。已有桌面客户端可检查更新，也可退出客户端后运行安装包覆盖升级。

Hub 无需更新，继续使用 1.50.1（wind.d3-view.cn）。

发行附件包含安装包、`.blockmap` 差分更新文件、`latest.yml` 更新元数据和 SHA-256 校验文件。可在 PowerShell 中用 `Get-FileHash -Algorithm SHA256 <安装包路径>` 对照同一版本的 `SHA256SUMS`。

Windows 安装包尚未配置代码签名。此版本仅发行 Windows。
