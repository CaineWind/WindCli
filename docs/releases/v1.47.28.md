# WindAgent 1.47.28 · Windows

正式发行页：https://github.com/CaineWind/WindCli/releases/tag/v1.47.28

Windows x64 安装包：https://github.com/CaineWind/WindCli/releases/download/v1.47.28/windagent-desktop-1.47.28-win-x64.exe

## 本次更新

- Super Agent 围绕项目保留协调员对话、团队群聊、事件与工单记录，可以把明确的任务委派给团队成员推进。
- 以 Pi 为主要集成路径，保留成员各自的会话和 Git 工作区；内部 worker 会话不再挤占普通对话列表。
- 支持成员头像、群聊成员选择与 @ 提及，并统一 Super Agent、权限盾牌菜单和诊断界面的视觉风格。
- 改进开发模式下桌面端与本机后端的连接，修复 Windows 文件身份比较精度与图片路径大小写和 8.3 短路径问题。

## 安装与更新

这是 Windows x64 的正式稳定版本，包含配套本机 Agent 服务及其运行依赖。安装客户端不需要额外安装 Node.js 或独立服务。已有桌面客户端可检查更新，也可退出客户端后运行安装包覆盖升级。

发行附件包含安装包、`.blockmap` 差分更新文件、`latest.yml` 更新元数据和 SHA-256 校验文件。可在 PowerShell 中用 `Get-FileHash -Algorithm SHA256 <安装包路径>` 对照同一版本的 `SHA256SUMS`。

## 体验项目团队

1. 在本机配置好 Pi 和可用模型，确认普通 Pi 对话可以正常回复。
2. 打开一个项目，在 Bots 页面配置该项目的团队成员与模型，然后进入 Super Agent。
3. 给协调员一个具体目标、项目范围和可验证的完成条件；需要团队执行时，明确要求委派给团队。
4. 在群聊与监督区域查看成员回复、工单状态、问题和产出，再验收实际代码及测试结果。

首次打开页面不会自动启动模型或事件自动化。事件规则默认暂停、观察，启用前按项目需求配置。模型缺少计价数据时，带美元费用上限的目标会被阻止执行；可使用有可靠计价数据的模型，费用守卫不会把未知费用当成零。

Windows 安装包尚未配置代码签名。历史 macOS 安装包保留在原发行页；此版本仅发行 Windows。
