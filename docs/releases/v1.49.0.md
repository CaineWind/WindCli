# WindAgent 1.49.0 · Windows

正式发行页：https://github.com/CaineWind/WindCli/releases/tag/v1.49.0

Windows x64 安装包：https://github.com/CaineWind/WindCli/releases/download/v1.49.0/windagent-desktop-1.49.0-win-x64.exe

## 本次更新

这是 1.47.28 之后的第一个公开版本，同时包含未单独发布的 1.48.0 改动。

- **管家**：右侧的小机器人打开账户级的管家，它在所有项目之上，记得你的习惯（记忆可在管家的「记忆」页查看和编辑），能读取和操作应用里的会话、项目、文件、Git、目标、定时任务和设置，并把事情交给项目 Bot 去做。除读取、记忆和打开页面外，管家的改动默认都要你批准；可以按类别放开普通写操作，执行、合并、推送、删除等始终询问。
- **多台机器**：连接 Hub 时，管家运行在你选定的一台机器上，可以直接读取你其他机器上的内容；修改你自己的其他机器只需批准一次；别人的机器仍需对方批准。管家的记忆保存在 Hub 账户下，你的机器共享同一份。
- **「需要你处理」收件箱**：顶栏的铃铛汇总所有机器上待批准的 Agent 操作、工具权限、目标和项目 Bot 工单，可以就地批准。
- **项目 Bot 页面**：改为「团队群聊 / 工作 / 需要你 / 设置」四个标签；会话里的多人模式统一叫「群聊」。
- 1.48.0 的改动：Agent 编辑器在 Agent 库、Super Agent 角色与团队之间共用；Codex 压缩历史可读取和搜索；本机数据默认迁到 `~/.windagent`；开发版与正式版桌面端互不干扰。

完整列表见发行页说明。

## 安装与更新

这是 Windows x64 的正式稳定版本，包含配套本机 Agent 服务及其运行依赖，不需要额外安装 Node.js 或独立服务。已有桌面客户端可检查更新，也可退出客户端后运行安装包覆盖升级。

管家固定使用 Pi，请先在本机配置好 Pi 和可用模型。使用 Hub 时，Hub 需为 1.49.0（wind.d3-view.cn 已更新），旧 Hub 不支持管家的跨机器读取、修改和记忆同步。

发行附件包含安装包、`.blockmap` 差分更新文件、`latest.yml` 更新元数据和 SHA-256 校验文件。可在 PowerShell 中用 `Get-FileHash -Algorithm SHA256 <安装包路径>` 对照同一版本的 `SHA256SUMS`。

Windows 安装包尚未配置代码签名。此版本仅发行 Windows。
