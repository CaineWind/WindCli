# WindAgent 1.50.1 · Windows

正式发行页：https://github.com/CaineWind/WindCli/releases/tag/v1.50.1

Windows x64 安装包：https://github.com/CaineWind/WindCli/releases/download/v1.50.1/windagent-desktop-1.50.1-win-x64.exe

## 本次更新

1.50.0 是未发布的候选版本，1.50.1 包含它的全部改动和两处修复。

- **管家自主**：管家设置里有三档——完全自主（默认）、只放开修改、逐项询问。完全自主时，修改、删除和付费工作直接执行（也包括你的其他机器），付费工作受每日预算约束（默认 20 美元，另有每天 50 次付费启动的上限）。推送、发布和删除项目始终询问。安装 MCP/技能和 Git 无法恢复的删除默认仍询问，可以在收件箱点「总是允许」放开，管家设置里可以撤回。
- **一步创建团队**：选阵容（单人开发员、开发员和审查员、完整团队），模型默认用执行器自己的默认模型；创建前检查执行器是否安装并登录、模型是否存在、项目是否有提交和 Git 提交身份。已有相同角色和模型的 Agent 会被复用。新团队自动成为「此项目的团队」，新建目标、项目 Bot 和群聊都从它开始。
- **管理团队**：改名、加减成员，查看每个成员的完成任务数、一次通过率和费用，并给出建议；任务失败后可以交给更强模型的开发员；多个开发员时，规划员按描述给任务挑人；删除团队可以连同它创建的 Agent 一起删除。
- **团队可以带走**：导出、导入团队文件，保存到项目的 `.windagent/team.json`，连接 Hub 时复制到你的其他机器。项目命令可以从 package.json、Makefile、pyproject.toml、go.mod、Cargo.toml 自动识别。
- **经 Hub 同步 Agent 和团队**：你名下的机器自动保持同一份 Agent 和团队；每台机器可以给同一个 Agent 选自己的模型。
- 员工运行失败时会显示提供商给出的原因。

完整列表见发行页说明。

## 安装与更新

这是 Windows x64 的正式稳定版本，包含配套本机 Agent 服务及其运行依赖，不需要额外安装 Node.js 或独立服务。已有桌面客户端可检查更新，也可退出客户端后运行安装包覆盖升级。

管家和一步创建的团队默认使用 Pi，请先在本机配置好 Pi 和可用模型，并确认默认模型能正常登录。跨机器同步 Agent 和团队需要 Hub 1.50.1（wind.d3-view.cn 已更新）；旧 Hub 上它们只留在各自机器。

发行附件包含安装包、`.blockmap` 差分更新文件、`latest.yml` 更新元数据和 SHA-256 校验文件。可在 PowerShell 中用 `Get-FileHash -Algorithm SHA256 <安装包路径>` 对照同一版本的 `SHA256SUMS`。

Windows 安装包尚未配置代码签名。此版本仅发行 Windows。
